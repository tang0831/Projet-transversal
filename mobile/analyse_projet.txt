# ANALYSE DE L'ARCHITECTURE LOGICIELLE - PROJET TOKANA ID (MOBILE)

## 1. SERVICES ET LOGIQUE MÉTIER

### Classe / Module : api.js (Axios Instance)
*Responsabilité : Gestion des communications HTTP avec le backend.*
- **Attributs :**
  - `BASE_URL`: URL dynamique détectée selon l'environnement (Émulateur vs Physique).
- **Méthodes :**
  - `getBaseUrl()`: Détermine l'adresse IP du serveur.
  - `api.interceptors`: Intercepteurs pour le logging des erreurs globales.

### Classe / Module : authService
*Responsabilité : Services d'authentification et d'inscription.*
- **Méthodes :**
  - `login(nom, mot_de_passe)`: Authentifie l'utilisateur.
  - `register(userData)`: Crée un nouveau compte utilisateur.

---

## 2. ÉCRANS ET COMPOSANTS (LOGIQUE UI)

### Classe / Écran : Login
*Responsabilité : Interface de connexion.*
- **Attributs (State) :**
  - `nom`: Identifiant saisi.
  - `password`: Mot de passe saisi.
  - `loading`: État de chargement.
- **Méthodes :**
  - `handleLogin()`: Valide les champs et appelle `authService.login`.

### Classe / Écran : Register
*Responsabilité : Création de compte avec sélection de localité.*
- **Attributs (State) :**
  - `nom`, `password`, `role`: Informations de base.
  - `localites`: Liste des communes disponibles.
  - `selectedLoc`: Localité choisie par l'utilisateur.
  - `isManualEntry`: Toggle pour saisie manuelle d'une localité.
- **Méthodes :**
  - `fetchLocalites()`: Récupère les communes via l'API.
  - `handleSearchLoc(text)`: Filtre la liste des localités.
  - `handleRegister()`: Soumet les données au serveur.

### Classe / Écran : Home (Dashboard)
*Responsabilité : Centre de navigation et notifications.*
- **Attributs (State) :**
  - `user`: Données de l'utilisateur connecté.
  - `hasNewMessages`: Indicateur de nouveaux messages dans le forum.
- **Méthodes :**
  - `loadUserAndCheckMessages()`: Charge le profil et vérifie les messages non lus.

### Classe / Écran : Citoyens
*Responsabilité : Gestion CRUD de la base citoyenne.*
- **Attributs (State) :**
  - `citoyens`: Liste des citoyens.
  - `form`: Objet contenant les données du citoyen en cours d'édition.
  - `editingId`: ID du citoyen si modification en cours.
- **Méthodes :**
  - `fetchCitoyens(query)`: Récupère la liste (avec recherche optionnelle).
  - `handleSubmit()`: Enregistre ou met à jour un citoyen (POST/PUT).
  - `deleteCitoyen(id)`: Supprime un citoyen.
  - `exportPDF()`: Télécharge la liste formatée en PDF.
  - `startEdit(c)`: Initialise le mode édition.

### Classe / Écran : Actes
*Responsabilité : Gestion des actes d'état civil (Naissance, Mariage, Décès).*
- **Attributs (State) :**
  - `actes`: Liste des actes indexés.
  - `form`: {type_acte, date_acte, numero_registre, id_citoyen}.
- **Méthodes :**
  - `fetchActes()`: Récupère les actes depuis le serveur.
  - `handleSubmit()`: Enregistre l'acte.
  - `deleteActe(id)`: Supprime l'acte.
  - `exportPDF()`: Génère le registre PDF.

### Classe / Écran : Forum
*Responsabilité : Communication entre les agents d'un même district.*
- **Attributs (State) :**
  - `messages`: Liste des messages reçus.
  - `newMsg`: Texte du message en cours de rédaction.
  - `user`: Infos utilisateur (pour filtrage par district).
- **Méthodes :**
  - `fetchMessages()`: Récupère les messages du district.
  - `sendMessage()`: Envoie un nouveau message.

### Classe / Écran : Profile
*Responsabilité : Gestion des informations personnelles.*
- **Attributs (State) :**
  - `user`: Profil utilisateur complet.
  - `acts`: Historique personnel des actes.
- **Méthodes :**
  - `pickImage()`: Ouvre la galerie pour changer la photo (Base64).
  - `updateProfile(updates)`: Met à jour les infos sur le serveur.
  - `handleLogout()`: Déconnexion et nettoyage du stockage local.

### Classe / Écran : Optimisation
*Responsabilité : Aide à la décision pour la logistique (Knapsack Algorithm).*
- **Attributs (State) :**
  - `budget`: Capacité maximale (numérique).
  - `items`: Liste des agents avec coûts et impacts.
  - `result`: Résultat du calcul d'optimisation.
- **Méthodes :**
  - `runOptimization()`: Appelle l'algorithme d'optimisation côté serveur.
